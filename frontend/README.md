# FormSaathi Frontend

React + Vite + Tailwind CSS frontend for FormSaathi, the voice-first multilingual citizen form filling assistant.

## Features
- **Voice-First Interaction**: Speech recognition (STT) and voice prompts (TTS) in Telugu (తెలుగు) & English.
- **Accessible UI**: Large touch targets, high-contrast colors, and simple language designed for elderly and rural citizens.
- **Mode 1 — Digital Assistant**: Natural conversation that collects information step by step without overwhelming 30-field forms.
- **Mode 2 — Physical Paper Form Assistant**: Upload physical form photos, see recognized fields, and view authentic layout-preserved filled forms.
- **Intelligent Conflict Resolver**: Flags discrepancies (such as DOB mismatch) and provides 1-click choices.
- **Instant Demo Presets**: Pre-configured buttons for seamless hackathon presentations.

## Running Locally

```bash
cd frontend
npm install
npm run dev
```

App runs at `http://localhost:5173`.
